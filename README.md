# Система управления Детским и Молодёжным Общественным Советом

Комплексная система для эффективного управления деятельностью Детского и Молодёжного Общественного Совета при Уполномоченном по правам ребёнка в Амурской области.

## Описание

Это веб-приложение предназначено для автоматизации и упрощения управления всеми аспектами работы совета, включая:

- **Управление членами совета** - учет информации о членах детского и молодёжного советов
- **Планирование мероприятий** - организация и отслеживание заседаний, конференций, семинаров, акций
- **Управление проектами** - контроль реализации социальных, образовательных и культурных проектов
- **Документооборот** - хранение и управление протоколами, отчетами, положениями
- **Отчетность и статистика** - автоматическое формирование отчетов о деятельности совета

## Функциональные возможности

### 1. Управление членами совета

- Полная информация о каждом члене (ФИО, возраст, контакты, образование)
- Разделение на детский и молодёжный советы
- Отслеживание статуса (активный/неактивный)
- Учет должностей и ролей
- Фиксация интересов, навыков и достижений

### 2. Планирование и учет мероприятий

- Создание и управление мероприятиями различных типов
- Календарь мероприятий
- Учет участников и посещаемости
- Отслеживание бюджета мероприятий
- Хранение материалов и фотографий

### 3. Управление проектами

- Планирование и мониторинг проектов
- Отслеживание прогресса выполнения (в процентах)
- Управление бюджетом проектов
- Назначение руководителей и участников
- Фиксация результатов и достижений

### 4. Документооборот

- Централизованное хранение документов
- Классификация по типам (отчеты, протоколы, положения и т.д.)
- Контроль версий документов
- Разграничение доступа (публичные, внутренние, ограниченные)
- Поиск по тегам

### 5. Отчетность

- Автоматическое формирование отчетов за период
- Статистика по членам, мероприятиям, проектам
- Финансовые показатели и эффективность использования бюджета
- Анализ достижений и проблемных областей
- Формирование рекомендаций

### 6. Панель управления

- Наглядная визуализация ключевых показателей
- Быстрый доступ к предстоящим мероприятиям
- Обзор активных проектов
- Статистика в реальном времени

## Технологии

### Backend
- **Python 3.8+** - основной язык программирования
- **Flask** - веб-фреймворк
- **SQLAlchemy** - ORM для работы с базой данных
- **Flask-CORS** - поддержка CORS запросов
- **SQLite** - база данных (легко мигрируется на PostgreSQL)

### Frontend
- **HTML5** - структура страниц
- **CSS3** - стилизация (адаптивный дизайн)
- **JavaScript (ES6+)** - интерактивность
- **Fetch API** - взаимодействие с backend

## Установка и запуск

### Требования

- Python 3.8 или выше
- pip (менеджер пакетов Python)

### Шаги установки

1. **Клонировать репозиторий**
```bash
git clone <repository-url>
cd youth-council-management
```

2. **Создать виртуальное окружение**
```bash
python3 -m venv venv
source venv/bin/activate  # На Windows: venv\Scripts\activate
```

3. **Установить зависимости**
```bash
pip install -r requirements.txt
```

4. **Запустить приложение**
```bash
python run.py
```

5. **Открыть в браузере**
```
http://localhost:5000
```

## API Документация

### Члены совета

#### GET /api/members/
Получить список всех членов совета
- Параметры: `status`, `council_type`, `position`

#### GET /api/members/:id
Получить информацию о конкретном члене

#### POST /api/members/
Создать нового члена совета

#### PUT /api/members/:id
Обновить информацию о члене

#### DELETE /api/members/:id
Удалить члена совета

#### GET /api/members/stats
Получить статистику по членам совета

### Мероприятия

#### GET /api/events/
Получить список мероприятий
- Параметры: `status`, `event_type`, `category`, `upcoming`

#### GET /api/events/:id
Получить информацию о мероприятии

#### POST /api/events/
Создать новое мероприятие

#### PUT /api/events/:id
Обновить мероприятие

#### DELETE /api/events/:id
Удалить мероприятие

#### POST /api/events/:id/participants
Добавить участника к мероприятию

#### GET /api/events/stats
Получить статистику по мероприятиям

### Проекты

#### GET /api/projects/
Получить список проектов
- Параметры: `status`, `project_type`, `category`

#### GET /api/projects/:id
Получить информацию о проекте

#### POST /api/projects/
Создать новый проект

#### PUT /api/projects/:id
Обновить проект

#### DELETE /api/projects/:id
Удалить проект

#### POST /api/projects/:id/members
Добавить участника к проекту

#### GET /api/projects/stats
Получить статистику по проектам

### Документы

#### GET /api/documents/
Получить список документов
- Параметры: `document_type`, `category`, `status`, `access_level`

#### GET /api/documents/:id
Получить информацию о документе

#### POST /api/documents/
Создать новый документ

#### PUT /api/documents/:id
Обновить документ

#### DELETE /api/documents/:id
Удалить документ

### Отчеты

#### GET /api/reports/
Получить список отчетов
- Параметры: `report_type`, `status`

#### GET /api/reports/:id
Получить информацию об отчете

#### POST /api/reports/
Создать новый отчет

#### PUT /api/reports/:id
Обновить отчет

#### DELETE /api/reports/:id
Удалить отчет

#### POST /api/reports/generate
Автоматически сгенерировать отчет за период

## Использование

### Добавление члена совета

1. Перейдите в раздел "Члены совета"
2. Нажмите кнопку "Добавить члена"
3. Заполните форму с информацией о члене
4. Нажмите "Сохранить"

### Создание мероприятия

1. Перейдите в раздел "Мероприятия"
2. Нажмите кнопку "Создать мероприятие"
3. Заполните информацию о мероприятии
4. Добавьте участников
5. Сохраните мероприятие

### Управление проектами

1. Перейдите в раздел "Проекты"
2. Создайте новый проект с описанием целей и задач
3. Назначьте руководителя и участников
4. Отслеживайте прогресс выполнения
5. Обновляйте статус и результаты

### Формирование отчета

1. Перейдите в раздел "Отчеты"
2. Нажмите "Создать отчет"
3. Выберите период отчетности
4. Система автоматически соберет статистику
5. Дополните отчет выводами и рекомендациями
6. Утвердите отчет

## Конфигурация

Основные настройки находятся в файле `config/config.py`:

- `SECRET_KEY` - секретный ключ для сессий (изменить в production!)
- `SQLALCHEMY_DATABASE_URI` - путь к базе данных
- `MAX_CONTENT_LENGTH` - максимальный размер загружаемых файлов
- `UPLOAD_FOLDER` - папка для загрузки файлов

### Переменные окружения

Можно установить следующие переменные окружения:

- `SECRET_KEY` - секретный ключ приложения
- `DATABASE_URL` - URL базы данных
- `PORT` - порт для запуска приложения (по умолчанию 5000)

## Безопасность

При развертывании в production обязательно:

1. Измените `SECRET_KEY` на уникальное значение
2. Используйте PostgreSQL вместо SQLite
3. Настройте HTTPS
4. Добавьте аутентификацию и авторизацию
5. Регулярно делайте резервные копии базы данных
