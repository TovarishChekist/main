# Telegram бот для приёма обращений

Официальный бот для приёма обращений к **Председателю Совета Первых** Первичного отделения «Движения первых».

## Возможности

### Для пользователей:
- ✍️ Подача обращений к Председателю
- 📊 Просмотр своих обращений
- ℹ️ Информация о Движении Первых
- ❓ Справка по использованию

### Для администраторов:
- 📋 Просмотр всех обращений
- 🆕 Фильтр новых обращений
- 📈 Статистика обращений
- ✅ Отметка обращений как обработанных
- 🔔 Автоматические уведомления о новых обращениях

## Установка

### 1. Клонирование репозитория

```bash
git clone <repository-url>
cd <repository-name>
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Настройка бота

1. Создайте бота через [@BotFather](https://t.me/BotFather)
2. Получите токен бота
3. Узнайте свой Telegram ID через [@userinfobot](https://t.me/userinfobot)
4. Скопируйте `.env.example` в `.env`:

```bash
cp .env.example .env
```

5. Отредактируйте `.env` и укажите:
   - `BOT_TOKEN` — токен вашего бота
   - `ADMIN_ID` — ваш Telegram ID

### 4. Запуск бота

```bash
python bot.py
```

## Использование

### Для пользователей

1. Запустите бота командой `/start`
2. Выберите "✍️ Подать обращение"
3. Напишите текст вашего обращения
4. Получите номер обращения и ожидайте ответа

### Для администраторов

После запуска `/start` вы увидите расширенное меню:

- **📋 Все обращения** — просмотр всех обращений
- **🆕 Новые обращения** — только необработанные
- **📈 Статистика** — общая статистика
- **👤 Пользовательское меню** — переключение в обычный режим

При получении нового обращения администраторы получают уведомление с возможностью:
- ✅ Отметить как обработанное
- 📝 Просмотреть подробности

## Технологии

- **Python 3.8+**
- **aiogram 3.4.1** — асинхронная библиотека для Telegram Bot API
- **aiosqlite** — асинхронная работа с SQLite
- **python-dotenv** — управление переменными окружения

## База данных

Бот использует SQLite для хранения обращений. База создаётся автоматически при первом запуске.

### Структура таблицы `appeals`:

| Поле | Тип | Описание |
|------|-----|----------|
| id | INTEGER | Уникальный ID обращения |
| user_id | INTEGER | Telegram ID пользователя |
| username | TEXT | Username пользователя |
| full_name | TEXT | Полное имя пользователя |
| appeal_text | TEXT | Текст обращения |
| created_at | TIMESTAMP | Дата и время создания |
| status | TEXT | Статус (new/processed) |

## Дополнительные администраторы

Для добавления нескольких администраторов укажите их ID через запятую в `.env`:

```env
ADMIN_ID=123456789
ADDITIONAL_ADMINS=987654321,111222333
```
