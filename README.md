# 🔐 Продвинутый Telegram Бот-Шифровальщик

Профессиональный бот для шифрования сообщений и файлов в Telegram с поддержкой множественных криптографических алгоритмов и end-to-end шифрования.

## ✨ Возможности

### 🔒 Режимы шифрования

1. **AES-256-GCM** (симметричное)
   - Шифрование с паролем
   - Authenticated encryption (защита от модификации)
   - Быстрое и безопасное

2. **ChaCha20-Poly1305** (симметричное)
   - Современная альтернатива AES
   - Отличная производительность на мобильных устройствах
   - Высокий уровень безопасности

3. **RSA-4096** (асимметричное)
   - Шифрование с публичным ключом
   - Подходит для небольших сообщений (до 470 байт)
   - Не требует обмена паролями

4. **Гибридное шифрование (RSA + AES)**
   - Комбинация RSA и AES
   - Для сообщений любого размера
   - Максимальная безопасность и производительность

### 📁 Шифрование файлов

- Потоковая обработка для файлов любого размера
- Минимальное использование памяти
- Сохранение метаданных

### 🔑 Управление ключами

- Автоматическая генерация RSA-4096 ключей
- Безопасное хранение приватных ключей (зашифрованы master-ключом)
- Управление общими ключами для E2E переписки
- Статистика использования

### 🛡️ Безопасность

- **PBKDF2** для деривации ключей из паролей (600,000 итераций)
- **Fernet** для шифрования приватных ключей в БД
- Все приватные данные шифруются перед сохранением
- Пароли никогда не сохраняются
- Timing-attack защита для сравнения ключей

## 🚀 Установка

### Требования

- Python 3.9+
- pip

### Шаги установки

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd telegram-encryption-bot
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Создайте `.env` файл:
```bash
cp .env.example .env
```

4. Получите токен бота от [@BotFather](https://t.me/BotFather) в Telegram

5. Добавьте токен в `.env`:
```env
TELEGRAM_BOT_TOKEN=your_bot_token_here
```

6. Запустите бота:
```bash
python bot.py
```

## 📖 Использование

### Команды

- `/start` - Начать работу с ботом, создать ключи
- `/menu` - Показать главное меню
- `/keys` - Показать информацию о ваших ключах

### Шифрование текста

1. Нажмите "🔐 Зашифровать текст"
2. Выберите режим шифрования
3. Отправьте текст для шифрования
4. Для AES/ChaCha - введите пароль
5. Получите зашифрованное сообщение

### Расшифровка текста

1. Нажмите "🔓 Расшифровать текст"
2. Отправьте зашифрованное сообщение (JSON)
3. Для AES/ChaCha - введите пароль
4. Получите расшифрованный текст

### Шифрование файлов

1. Нажмите "📁 Зашифровать файл"
2. Отправьте файл
3. Выберите режим и введите пароль
4. Получите зашифрованный файл

## 🔐 Криптографические детали

### Алгоритмы

- **AES-256-GCM**: 256-битный ключ, 96-битный nonce, аутентифицированное шифрование
- **ChaCha20-Poly1305**: 256-битный ключ, 96-битный nonce, AEAD
- **RSA-4096**: 4096-битный модуль, OAEP padding с SHA-256
- **PBKDF2**: SHA-256, 600,000 итераций, 256-битная соль

### Хранение данных

- SQLite база данных для ключей
- Приватные ключи шифруются Fernet (AES-128-CBC + HMAC)
- Master-ключ хранится в файле с правами 600 (только владелец)

## 🛡️ Безопасность

### Рекомендации

1. **Никогда не делитесь приватным ключом**
2. **Используйте сильные пароли** (минимум 12 символов)
3. **Регулярно делайте бэкап** master-ключа
4. **Запускайте бота на защищенном сервере**
5. **Используйте HTTPS** для webhook (если применимо)

### Ограничения

- Бот хранит зашифрованные ключи в локальной БД
- Master-ключ хранится на диске (можно переместить в HSM для production)
- Telegram API имеет доступ к метаданным сообщений (но не к содержимому)
