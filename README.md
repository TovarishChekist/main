# Telegram-бот Детского и Молодёжного Общественного Совета

Официальный Telegram-бот при Уполномоченном по правам ребёнка в Амурской области.

## Описание

Бот предназначен для взаимодействия детей и молодёжи с Общественным Советом. Он позволяет:

- 📩 **Отправлять обращения** - делиться проблемами, идеями и предложениями
- 📝 **Подавать заявки на вступление** - стать частью команды активных ребят
- ℹ️ **Получать информацию** - узнать о целях и задачах Совета
- 👥 **Знакомиться с руководством** - увидеть состав управления Совета

## Функционал

### Для пользователей:
- Простой и понятный интерфейс с кнопками
- Пошаговое заполнение заявки на вступление
- Возможность отправки обращений напрямую в Совет
- Получение ответов от администрации Совета

### Для администраторов:
- Все обращения пересылаются в специальный чат
- Все заявки на вступление пересылаются в отдельный чат
- Возможность ответить пользователю прямо из чата Совета

## Установка

### Требования

- Python 3.8 или выше
- pip (менеджер пакетов Python)

### Шаги установки

1. **Клонируйте репозиторий:**
```bash
git clone <url-репозитория>
cd <название-репозитория>
```

2. **Создайте виртуальное окружение (рекомендуется):**
```bash
python -m venv venv
```

3. **Активируйте виртуальное окружение:**

На Linux/Mac:
```bash
source venv/bin/activate
```

На Windows:
```bash
venv\Scripts\activate
```

4. **Установите зависимости:**
```bash
pip install -r requirements.txt
```

5. **Настройте переменные окружения:**

Скопируйте файл `.env.example` в `.env`:
```bash
cp .env.example .env
```

Отредактируйте файл `.env` и укажите свои значения:
```env
BOT_TOKEN=ваш_токен_от_BotFather
APPEAL_CHAT_ID=-1234567890123
APPLICATION_CHAT_ID=-9876543210987
```

### Получение токена бота

1. Найдите [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания бота
4. Скопируйте полученный токен в файл `.env`

### Получение ID чатов

Для получения ID группового чата:
1. Добавьте бота [@userinfobot](https://t.me/userinfobot) в ваш чат
2. ID чата будет показан (начинается с `-`)
3. Удалите @userinfobot из чата
4. Укажите ID в файле `.env`

## Запуск

```bash
python bot.py
```

Бот начнёт работу и будет выводить логи в консоль и в файл `bot.log`.

## Использование

### Команды бота:

- `/start` - Запуск бота и отображение главного меню

### Меню:

1. **📩 Обращение в Совет** - Отправить своё обращение
2. **📝 Заявка на вступление** - Подать заявку на вступление в Совет
3. **ℹ️ Информация о Совете** - Узнать о миссии и целях Совета
4. **👥 Руководство Совета** - Посмотреть состав руководства

### Процесс подачи заявки:

Заявка состоит из 7 шагов:
1. ФИО
2. Возраст
3. Школа обучения
4. Класс
5. Никнейм в Telegram
6. Мотивация вступления
7. Опыт общественной деятельности
8. Контакты для связи

После заполнения всех полей заявка автоматически отправляется в чат администраторов.

### Ответы пользователям:

Администраторы могут ответить пользователю, просто ответив (Reply) на сообщение в чате Совета. Ответ автоматически будет отправлен пользователю.

## Безопасность

- Токен бота и ID чатов хранятся в файле `.env`, который не загружается в репозиторий
- Все конфиденциальные данные защищены через `.gitignore`
- Логирование всех действий для отслеживания проблем

## Логирование

Бот ведёт подробные логи:
- Выводятся в консоль для мониторинга в реальном времени
- Сохраняются в файл `bot.log` для последующего анализа
- Уровни логирования: INFO, WARNING, ERROR

## Решение проблем

### Бот не запускается

1. Проверьте, что файл `.env` создан и содержит корректный токен
2. Убедитесь, что установлены все зависимости: `pip install -r requirements.txt`
3. Проверьте версию Python: `python --version` (должна быть 3.8+)

### Бот не отвечает на сообщения

1. Проверьте логи в файле `bot.log`
2. Убедитесь, что бот имеет доступ к интернету
3. Проверьте, что токен бота действителен

### Не приходят сообщения в чаты Совета

1. Проверьте, что ID чатов в `.env` указаны правильно (должны начинаться с `-`)
2. Убедитесь, что бот добавлен в эти чаты
3. Проверьте, что бот имеет права на отправку сообщений в эти чаты

## Развёртывание на сервере

### Использование systemd (Linux)

Создайте файл `/etc/systemd/system/youth-council-bot.service`:

```ini
[Unit]
Description=Youth Council Telegram Bot
After=network.target

[Service]
Type=simple
User=your_user
WorkingDirectory=/path/to/bot
Environment="PATH=/path/to/bot/venv/bin"
ExecStart=/path/to/bot/venv/bin/python /path/to/bot/bot.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

Активируйте сервис:
```bash
sudo systemctl daemon-reload
sudo systemctl enable youth-council-bot
sudo systemctl start youth-council-bot
```

Проверка статуса:
```bash
sudo systemctl status youth-council-bot
```

### Использование screen (простой способ)

```bash
screen -S youth-bot
python bot.py
# Нажмите Ctrl+A, затем D для отсоединения
```

Вернуться к боту:
```bash
screen -r youth-bot
```
