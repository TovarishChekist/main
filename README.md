# 📱 Telegram бот для приёма обращений

Бот для приёма обращений Председателю Совета Первых Первичного отделения «Движения первых».

## ✨ Возможности

### Для пользователей:
- 📝 Отправка обращений Председателю
- 📋 Просмотр истории своих обращений
- 🔄 Отслеживание статуса обращений
- ✉️ Получение ответов на обращения

### Для администратора:
- 🔔 Уведомления о новых обращениях
- ✅ Принятие обращений в работу
- ✏️ Ответ на обращения
- 📊 Управление статусами обращений

## 🚀 Установка и запуск

### 1. Создайте Telegram бота

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям и получите токен бота
4. Сохраните токен в надёжном месте

### 2. Узнайте свой Telegram ID

1. Откройте [@userinfobot](https://t.me/userinfobot) в Telegram
2. Нажмите `/start`
3. Бот пришлёт вам ваш ID

### 3. Установите зависимости

```bash
# Установите Python 3.8 или выше, если ещё не установлен

# Установите зависимости
pip install -r requirements.txt
```

### 4. Настройте окружение

```bash
# Скопируйте файл с примером
cp .env.example .env

# Отредактируйте .env файл и укажите:
# - BOT_TOKEN (токен от @BotFather)
# - ADMIN_ID (ваш Telegram ID)
```

### 5. Запустите бота

```bash
python main.py
```

Бот готов к работе! 🎉

## 📝 Использование

### Для пользователей:

1. Найдите вашего бота в Telegram по username
2. Нажмите `/start`
3. Выберите "📝 Отправить обращение"
4. Напишите текст обращения
5. Ожидайте ответа от Председателя

### Для администратора:

1. Вам будут приходить уведомления о новых обращениях
2. Используйте кнопки для управления обращениями:
   - ✅ Принять в работу
   - ✏️ Ответить
   - 📋 Закрыть
3. Команда `/admin` - просмотр панели администратора

## 📁 Структура проекта

```
.
├── main.py                 # Точка входа
├── requirements.txt        # Зависимости
├── .env                    # Переменные окружения (не в Git)
├── .env.example           # Пример переменных окружения
├── bot/
│   ├── config.py          # Конфигурация бота
│   ├── keyboards.py       # Клавиатуры и кнопки
│   └── handlers.py        # Обработчики команд
└── database/
    ├── db.py              # Работа с базой данных
    └── appeals.db         # База данных SQLite (создаётся автоматически)
```

## 🛠️ Технологии

- [aiogram 3.3.0](https://aiogram.dev/) - асинхронная библиотека для Telegram Bot API
- [aiosqlite](https://github.com/omnilib/aiosqlite) - асинхронная работа с SQLite
- [python-dotenv](https://github.com/theskumar/python-dotenv) - управление переменными окружения

## 📊 Статусы обращений

- 🆕 **Новое** - обращение только что создано
- ⏳ **В работе** - обращение принято администратором
- ✅ **Закрыто** - на обращение дан ответ

## 🔒 Безопасность

- Токен бота хранится в `.env` файле и не попадает в Git
- Только указанный администратор может управлять обращениями
- База данных SQLite хранится локально
