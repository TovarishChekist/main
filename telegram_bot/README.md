# Telegram Bot - Детский и Молодёжный Общественный Совет

Официальный бот Детского и Молодёжного Общественного Совета при Уполномоченном по правам ребёнка в Амурской области.

## Версия 2.0

Полностью переработанная версия бота с улучшенной архитектурой, безопасностью и функциональностью.

## Возможности

- **Обращения в Совет** - пользователи могут отправлять свои вопросы и предложения
- **Заявки на вступление** - возможность подать заявку на вступление в Совет
- **Информация о Совете** - информация о целях и задачах Совета
- **Руководство Совета** - информация о руководящем составе
- **Автоматическая валидация** - проверка корректности введенных данных
- **Ответы администраторов** - возможность отвечать пользователям из групп Telegram

## Установка

### 1. Клонирование репозитория

```bash
git clone <repository_url>
cd telegram_bot
```

### 2. Создание виртуального окружения

```bash
python3 -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка переменных окружения

Скопируйте файл `.env.example` в `.env` и заполните необходимые данные:

```bash
cp .env.example .env
```

Отредактируйте файл `.env`:

```env
BOT_TOKEN=ваш_токен_от_BotFather
APPEAL_CHAT_ID=-1002863620257
APPLICATION_CHAT_ID=-1002692926810
LOG_LEVEL=INFO
```

### 5. Получение токена бота

1. Найдите [@BotFather](https://t.me/botfather) в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания бота
4. Скопируйте полученный токен в файл `.env`

### 6. Получение ID чатов

Чтобы получить ID группы:

1. Добавьте бота [@userinfobot](https://t.me/userinfobot) в вашу группу
2. Бот отправит ID группы
3. Используйте этот ID в файле `.env`

## Логирование

Логи сохраняются в директории `logs/`:
- `bot.log` - основной файл логов
- Также выводятся в консоль

Уровни логирования можно настроить в `.env` через параметр `LOG_LEVEL`:
- `DEBUG` - подробная информация для отладки
- `INFO` - общая информация о работе (по умолчанию)
- `WARNING` - предупреждения
- `ERROR` - ошибки
- `CRITICAL` - критические ошибки

## Особенности версии 2.0

### Улучшения безопасности

- Все конфиденциальные данные вынесены в переменные окружения
- Токен бота и ID чатов не хранятся в коде
- Файл `.env` добавлен в `.gitignore`

### Архитектура

- Модульная структура кода
- Разделение логики на отдельные модули
- Использование классов для организации кода
- Централизованное управление состояниями

### Валидация данных

- Проверка ФИО (минимум Фамилия + Имя)
- Валидация возраста (10-25 лет)
- Проверка формата класса (5-11, с опциональной буквой)
- Валидация никнейма Telegram
- Проверка длины текстовых полей

### Обработка ошибок

- Безопасное удаление сообщений
- Логирование всех операций
- Graceful shutdown при получении сигналов
- Обработка исключений в критических местах

### Юзабилити

- Понятные сообщения об ошибках
- Автоматическое удаление служебных сообщений
- Плавная навигация по меню
- Возможность отмены операции на любом этапе

## Разработка

### Добавление нового текста

Все тексты находятся в `src/messages.py`. Добавьте новое сообщение в класс `Messages`:

```python
NEW_MESSAGE = """<b>Заголовок</b>

Текст сообщения"""
```

### Добавление новой клавиатуры

Клавиатуры описаны в `src/keyboards.py`:

```python
@staticmethod
def new_keyboard() -> ReplyKeyboardMarkup:
    markup = ReplyKeyboardMarkup(resize_keyboard=True)
    markup.add(KeyboardButton("Кнопка 1"))
    markup.add(KeyboardButton("Кнопка 2"))
    return markup
```

### Добавление нового обработчика

Обработчики находятся в `src/handlers.py`. Добавьте новый метод в класс `BotHandlers` и зарегистрируйте его в методе `register_handlers()`.

## Troubleshooting

### Бот не отвечает

1. Проверьте корректность токена в `.env`
2. Убедитесь, что бот запущен
3. Проверьте логи в `logs/bot.log`

### Ошибки валидации конфигурации

1. Проверьте наличие файла `.env`
2. Убедитесь, что все обязательные параметры заполнены
3. Проверьте корректность ID чатов (должны быть отрицательными числами)

### Не приходят сообщения в группу

1. Убедитесь, что бот добавлен в группу
2. Проверьте права бота в группе (должен иметь возможность отправлять сообщения)
3. Проверьте корректность ID группы
