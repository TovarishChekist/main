# Быстрый старт

Это краткое руководство поможет быстро запустить систему управления советом.

## Установка за 5 минут

### 1. Установите Python 3.8+

Убедитесь, что Python установлен:
```bash
python3 --version
```

### 2. Клонируйте репозиторий

```bash
git clone <repository-url>
cd youth-council-management
```

### 3. Создайте виртуальное окружение

```bash
python3 -m venv venv
source venv/bin/activate  # На Windows: venv\Scripts\activate
```

### 4. Установите зависимости

```bash
pip install -r requirements.txt
```

### 5. Запустите приложение

```bash
python run.py
```

### 6. Откройте браузер

Перейдите по адресу: http://localhost:5000

## Первые шаги

### Добавьте первого члена совета

1. Откройте раздел "Члены совета"
2. Нажмите "Добавить члена"
3. Заполните форму
4. Сохраните

### Создайте мероприятие

1. Перейдите в раздел "Мероприятия"
2. Используйте API для создания мероприятия (форма будет добавлена позже)

Пример через curl:
```bash
curl -X POST http://localhost:5000/api/events/ \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Первое заседание",
    "start_datetime": "2024-12-01T14:00:00",
    "status": "planned"
  }'
```

### Создайте проект

Аналогично мероприятиям, используйте API:
```bash
curl -X POST http://localhost:5000/api/projects/ \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Первый проект",
    "start_date": "2024-12-01",
    "status": "active"
  }'
```

### Сгенерируйте отчет

```bash
curl -X POST http://localhost:5000/api/reports/generate \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Тестовый отчет",
    "period_start": "2024-01-01",
    "period_end": "2024-12-31"
  }'
```

## Структура данных

### Члены совета
- ФИО, дата рождения
- Контакты (email, телефон)
- Тип совета (Детский/Молодёжный)
- Должность и статус
- Интересы и навыки

### Мероприятия
- Название и описание
- Тип и категория
- Дата и время
- Место проведения
- Список участников

### Проекты
- Название и описание
- Цели и задачи
- Сроки и бюджет
- Прогресс выполнения
- Команда проекта

### Документы
- Тип документа
- Файл и метаданные
- Связь с проектами/мероприятиями

### Отчеты
- Период отчетности
- Автоматическая статистика
- Достижения и проблемы
- Рекомендации

## Основные API endpoints

### Статистика
```bash
# Статистика по членам
curl http://localhost:5000/api/members/stats

# Статистика по мероприятиям
curl http://localhost:5000/api/events/stats

# Статистика по проектам
curl http://localhost:5000/api/projects/stats
```

### Фильтрация
```bash
# Активные члены детского совета
curl "http://localhost:5000/api/members/?status=active&council_type=Детский"

# Предстоящие мероприятия
curl "http://localhost:5000/api/events/?upcoming=true"

# Активные проекты
curl "http://localhost:5000/api/projects/?status=active"
```
