# 🚀 Быстрая инструкция по настройке

## Шаг 1: Получение токена

1. Откройте Telegram
2. Найдите бота **@BotFather**
3. Отправьте команду `/newbot`
4. Придумайте имя для бота (например: `My Encryption Bot`)
5. Придумайте username для бота (должен заканчиваться на `bot`, например: `my_encryption_bot`)
6. BotFather отправит вам токен, который выглядит примерно так:
   ```
   1234567890:ABCdefGHIjklMNOpqrsTUVwxyz-1234567
   ```
7. **Скопируйте этот токен** (он вам понадобится в следующем шаге)

## Шаг 2: Настройка .env файла

### На PythonAnywhere:

1. Перейдите в раздел **Files**
2. Откройте папку с вашим проектом (например: `/home/ваш-username/main`)
3. Создайте новый файл `.env` (нажмите **New file**)
4. Добавьте в него:
   ```env
   TELEGRAM_BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz-1234567
   ```
   ⚠️ **Замените** `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz-1234567` на ваш реальный токен!

5. Сохраните файл

### На локальном компьютере:

1. Откройте терминал в папке проекта
2. Скопируйте пример:
   ```bash
   cp .env.example .env
   ```
3. Откройте `.env` в любом текстовом редакторе
4. Замените `your_bot_token_here` на ваш токен:
   ```env
   TELEGRAM_BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz-1234567
   ```
5. Сохраните файл

## Шаг 3: Проверка

Правильный `.env` файл должен выглядеть так:

```env
TELEGRAM_BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz-1234567
```

**Важно:**
- Не должно быть пробелов вокруг `=`
- Токен должен быть полным (обычно 45-50 символов)
- Не добавляйте кавычки вокруг токена
- Файл называется именно `.env` (с точкой в начале)

## Шаг 4: Запуск бота

### На PythonAnywhere (Webhook):

1. В разделе **Web** нажмите кнопку **Reload**
2. Откройте Telegram и найдите вашего бота
3. Отправьте `/start`

### На локальном компьютере:

```bash
# Linux/Mac:
./start.sh

# Или вручную:
python bot.py
```

### Windows:
```cmd
python bot.py
```

## Частые ошибки

### ❌ "Token is invalid!"

**Причина:** Токен не установлен или неверный

**Решение:**
1. Проверьте, что файл `.env` существует
2. Проверьте, что токен скопирован полностью
3. Убедитесь, что нет лишних пробелов
4. Проверьте правильность написания: `TELEGRAM_BOT_TOKEN` (заглавными буквами)

### ❌ "ModuleNotFoundError: No module named 'dotenv'"

**Решение:**
```bash
pip install python-dotenv
# или
pip install -r requirements.txt
```

### ❌ Бот не отвечает

**Проверьте:**
1. Правильно ли установлен токен
2. Запущен ли бот (должна быть надпись "🚀 Бот запущен!")
3. Не заблокирован ли бот файрволом
4. Есть ли интернет соединение

## Безопасность

⚠️ **НИКОГДА не публикуйте токен в открытом доступе!**

- Не коммитьте `.env` файл в git (он уже в `.gitignore`)
- Не отправляйте токен в чаты
- Если токен был скомпрометирован:
  1. Откройте @BotFather
  2. Отправьте `/mybots`
  3. Выберите вашего бота
  4. Нажмите **API Token** → **Revoke current token**
  5. Обновите `.env` файл с новым токеном
